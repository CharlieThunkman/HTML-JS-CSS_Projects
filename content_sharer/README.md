## Content Sharer list
### Instructions on how to customize your experience.
* prefix first option with '?' 
* concatenate multiple url options with '&'
* options that need paramaters should declare 'name=value'

| option name | &nbsp;parameters&nbsp; | description |
| ---: | :---: | :--- |
| domain | url | The domain site. By default, this is Youtube.com |
| contents | string [REQUIRED] | The content ID on the youtube website or app. If the `domain=` parameter is omitted, this is only the 11 characters directly after the `v=` in the youtube url. Otherwise, this is everything after the domain in your specified site (omitting the `/` directly after the domain). To add multiple links to the same domain, seperate each entry with a `+`. |
| | ^ | For example in this video [https://www.youtube.com/watch?v=xxV7oxeryfc?si=aI9GCGrN10F6uOTj](https://youtu.be/xxV7oxeryfc), the only the  `xxV7oxeryfc` part is needed for the full parameter|
| author | string | The prefixed text attached to the list title, allowing people you share this link to remind them who they retrieved it from.
