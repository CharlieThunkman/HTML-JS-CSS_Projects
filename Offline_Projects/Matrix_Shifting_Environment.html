Matrix Shifting Environment

Designed to imitate valid movement types in Shapez 2

Logging Console:

System initialized. Column values matching their starting indices. Empty rows are marked 0.
When manual mode is active, use the arrow keys to navigate between steps in the animation to see exactly what is changing at your own pace. Shapez does not support the column shifts natively, which is why those movement types are in black containers in the button menu. Stacking is an option only available in the animation sequence as the idea is not to use the stacker, only the rotators, cutters, and swappers. All stored animations are pre-programmed by CharlieThunkman.
